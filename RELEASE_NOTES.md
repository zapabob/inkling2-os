# Inkling2-OS v0.1.1 — Boot-to-Inference Update

Development candidate. The Windows console exposes a locally installed Inkling2 CUDA Engine through a key-free loopback provider for Strata. It includes scoped document previews, a public HTTPS document view and RustXNG search. The Linux appliance also includes an offline Wine sandbox for 64-bit Windows command-line programs.

Virtual boot checks and paired release qualification are recorded in the [validation record](docs/V0.1.1_VALIDATION.md). The private USB installer uses a separate CUDA and model configuration for the target machine.
