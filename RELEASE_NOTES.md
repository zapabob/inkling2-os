# Inkling2-OS v0.1.1 — Boot-to-Inference Update

Development candidate. The Windows console can expose a locally installed Inkling2 CUDA Engine to Strata through a bearer-authenticated loopback provider. It also includes guarded document previews and an HTTPS text view.

Both firmware modes passed virtual boot checks. Promotion requires a qualified Linux engine and physical boot-to-inference evidence. See the [validation record](docs/V0.1.1_VALIDATION.md).
