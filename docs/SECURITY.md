# Security

Bind the console to an explicit loopback address. The request boundary verifies Host, Origin, Fetch Metadata and body framing. Personal state, files, browsing, voice and GPU controls require the console bearer. An independent inference bearer grants the model catalogue and completions. Chat text is not automatically written to Memory45. Credentials supplied by the Windows launcher are encrypted with DPAPI for the current user.

Finder resolves the configured shared directory through a directory handle. It refuses path traversal, links, hidden and sensitive-looking names, and previews of model or companion state. Share a directory containing only documents intended for this console. The file type and name rules do not inspect the sensitivity of the text inside an allowed document.

The browser requests public IPv4 destinations over HTTPS port 443. It validates DNS results, pins the actual destination, skips redirects and proxy configuration, and displays text in a console with a same-origin script policy. The service does not send API credentials to the requested website. Links, active documents and website execution are outside the feature’s scope.

The Linux ISO uses a default-deny inbound firewall and unprivileged bridge. Deployment partition changes, writable mounts and package installation require explicit operator action.
