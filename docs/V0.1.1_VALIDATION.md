# v0.1.1 validation

| Gate | Evidence |
| --- | --- |
| Release baseline | v0.1.0 release and annotated tag checked on GitHub. |
| Windows console | Built and opened a loopback preview. The real browser showed Chat, Finder FS, Browser, Memory & LoRA, Tensor Core, and Models & CLI. |
| Windows API | 13 live HTTP cases passed, including scoped authentication, origin and Host rejection, shared-directory access, public HTTPS, and disabled experimental LoRA. |
| Rust and CUDA | Windows formatting and Clippy passed. Windows and Linux each passed 14 Rust tests. The standalone Windows build used CUDA 13.5 and passed BF16, INT8 and NVFP4 Tensor Core checks on the RTX 5060 Ti. |
| Installed Strata 0.8.6 | Added and read back the custom OpenAI Chat Completions provider and its SQ-10 model. Existing provider records were preserved. |
| Native GPU admission | The completion endpoint initially returned 503 with roughly 3 GiB free of 16,311 MiB. |
| Native model output | With sufficient free VRAM, the bridge loaded the real SQ-10 weights and returned HTTP 200 after 91.46 seconds for an eight-token request. The model emitted repeated punctuation and failed the prompt. This measures the whole request, including model load. |
| Installed Strata generation | The app’s saved provider reached the bridge and correctly received the original 503. A subsequent quality probe could not be run through the desktop host after it closed. |
| ISO and virtual boot | The same candidate ISO passed BIOS and UEFI in diskless QEMU. The serial logs record the overlay root, PID 1, the GPU-absent diagnostic state, bridge health, recovery after a deliberate bridge termination, and guest power-off. |
| Linux inference and long context | Unverified. The standalone Windows executable cannot serve as a Linux engine. |
| Performance | A single Windows end-to-end round-trip was measured. Comparable cross-platform performance, output quality and long-context capacity remain unqualified. |

Confirm the candidate’s final command outputs and artefacts before any release. The branch is for local validation.
