## Subsequent native and appliance checks

Windows passed the 15 Rust workspace tests, Clippy with warnings denied and the separately enabled real-model tokenizer fixture. The template and token IDs agree with the independent Jinja and tokenizer reference. The key-free local Windows console also rendered a public search result from RustXNG full and read an approved local document through Finder.

The dedicated disk image reached UEFI, writable ext4, PID 1, the nftables firewall and the local startup health check in QEMU. Its original Wine configuration did not complete startup. A subsequent run of the revised Bubblewrap wrapper on Linux executed Windows `cmd.exe` and returned its expected marker with its network disconnected. Combined boot qualification of the private CUDA and model-volume bundle remains pending.

The Windows CUDA 13.5 candidate subsequently passed all three CTests on the RTX 5060 Ti. The directory test independently checked the body offset and placement priority for all 3,072 SQ-10 experts. The generation test used 29 input tokens and an eight-token output limit. It returned token 19 (the digit `4`) and stopped, matching Strata on the arithmetic fixture. The 187.77-second test includes loading the weights. It does not measure sustained decode speed.

The key-free console subsequently passed 11 live HTTP checks, including a public HTTPS document, the shared directory, and rejection of foreign origins and parent paths. A full-profile RustXNG query returned 11 results. The active GUI showed the SQ-10 model and RTX 5060 Ti telemetry. A direct request from the console to the corrected model was refused with HTTP 503 while another process occupied GPU memory. The CUDA CTest is the successful generation evidence for this candidate.

An installed-disk diagnostic on QEMU 10.2.1 booted through UEFI and executed Windows `cmd.exe` inside the offline Wine sandbox. Initialising the prefix and running the command took about 264 seconds. The same boot passed service restart, health and shutdown. This run used the previous disk image with the current Wine wrapper and an isolated 300-second probe override. The PID 1 source now uses that measured timeout. The rebuilt final ISO, the private USB bundle, physical Linux GPU generation and generation through the installed Strata desktop still require verification.
